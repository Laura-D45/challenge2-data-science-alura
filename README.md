# Challenge2-data-science-alura

## 📌 Descripción
Este proyecto presenta un **Análisis Exploratorio de Datos (EDA)** enfocado en comprender los factores asociados con la **evasión de clientes (Churn)** en una empresa de servicios.

El objetivo principal es analizar el comportamiento de los clientes y detectar patrones que ayuden a entender **por qué algunos clientes cancelan el servicio**, utilizando herramientas de análisis y visualización de datos.
###Ejercicio planteado por Alura

---

## 🎯 Objetivos del proyecto
- Analizar la distribución de clientes que cancelan el servicio.
- Explorar la relación entre el churn y variables demográficas, contractuales y de facturación.
- Identificar factores que influyen en la evasión de clientes.
- Generar insights que puedan apoyar estrategias de retención.

---

## 🛠 Tecnologías utilizadas
- **Python**
- **Pandas** → Manipulación y análisis de datos  
- **NumPy** → Operaciones numéricas  
- **Matplotlib / Seaborn** → Visualización de datos  
- **Jupyter Notebook** → Desarrollo del análisis

---

## 🔎 Análisis realizado
Durante el proyecto se realizaron las siguientes etapas:

1. **Importación y exploración inicial del dataset**
2. **Limpieza y tratamiento de datos**
3. **Normalización de estructuras JSON**
4. **Análisis exploratorio de datos (EDA)**
5. **Visualización de patrones de churn**
6. **Identificación de insights relevantes**
